# ton-press-web

東北大学新聞（東北大学学友会報道部）ウェブサイト https://ton-press.blogspot.com/ の **見た目と動き** を管理するリポジトリです。

記事そのものは今まで通り Blogger に保存され、記事の書き方・投稿の手順は変わりません。
このリポジトリで変えるのは、ページの色・配置・トップページの組み立てだけです。

## 仕組み（3行で）

1. **記事・コメント・人気記事** … Blogger が保存し、Blogger が HTML を組む
2. **見た目（`src/site.css`）と動き（`src/app.js`）** … このリポジトリに置き、[jsDelivr](https://www.jsdelivr.com/)（GitHub のファイルを無料で配る CDN）から配る
3. **Blogger のテーマ（`theme/theme.xml`）** … 上の 2 つを読み込むだけの「薄い殻」。ほぼ書き換えない

```
部員 ──記事を書く──▶ Blogger（記事・コメント・閲覧数）
                         │ ページを返す
読者 ◀──────────────── テーマ（殻）── 読み込む ──▶ jsDelivr ◀── GitHub（このリポジトリ）
```

詳しくは [docs/architecture.md](docs/architecture.md)。

## フォルダ

| 場所 | 中身 |
|---|---|
| `src/site.css` | 色・字・配置のすべて。色は冒頭の `:root` で変えられる |
| `src/app.js` | ヘッダー・フッター・トップページを組む。**冒頭の `CONFIG` でメニューやトップの並びを変えられる** |
| `src/assets/` | ロゴ・背景画像 |
| `theme/theme.xml` | Blogger に貼るテーマ（殻）。読み込む版番号が 2 か所に書いてある |
| `preview/` | 手元で見るための見本。記事は 2026-10-07 時点の写し（`data.js`） |
| `docs/` | 手順書 |

## 変更の流れ（いきなり本番に出さない）

```
① ブランチで直す → ② Pull Request → ③ 確認・承認してマージ
→ ④ 版（タグ）を打つ → ⑤ 試験用ブログで確認 → ⑥ 本番テーマの版番号を上げる
```

- 本番は **版番号（タグ）で固定** して読んでいる。⑥ をするまで、マージしても本番は 1 ミリも変わらない
- 戻すときは、本番テーマの版番号を 1 つ前に戻すだけ（[docs/release.md](docs/release.md#戻し方)）

| やりたいこと | 読む文書 |
|---|---|
| 色・メニュー・トップの並びを変えたい | [docs/editing.md](docs/editing.md) |
| 変更を本番に出したい／戻したい | [docs/release.md](docs/release.md) |
| 試験用ブログを作りたい | [docs/staging-blog.md](docs/staging-blog.md) |

## 手元で見る

`preview/index.html` をブラウザで開く（ビルドもインストールも不要）。
`preview/` は見本のデータで描くので、本番の記事は反映されない。

## 守ること

- **鍵・パスワード・個人情報をこのリポジトリに置かない**（公開リポジトリ。誰でも読める）
- **元のテーマ（ThemeForest で購入したもの）を置かない**。再配布になる
- `main` に直接 push しない。必ず Pull Request を通す
- 本番テーマを触る前に、Blogger の「テーマ → バックアップ」で現在のテーマを保存する
