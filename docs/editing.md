# よくある変更

どれも Pull Request で行い、[release.md](release.md) の手順で本番に出す。

## メニューを変える

`src/app.js` の冒頭、`CONFIG.nav` を直す。

```js
nav: [
  ['トップ', '/'],
  ['インタビュー', '/search/label/インタビュー'],   // ← [表示名, リンク先]
  ...
]
```

- ラベルの一覧へのリンクは `/search/label/<ラベル名>`
- 固定ページのリンクは Blogger の管理画面の「ページ」で確かめる（例：`/p/blog-page_41.html`）

## トップに並べるラベルを変える

`src/app.js` の `CONFIG.sections`。上から順にトップに並ぶ。

```js
sections: [
  ['インタビュー', 'INTERVIEW'],   // ← [Blogger のラベル名（完全一致）, 英字の小見出し]
  ...
]
```

**ラベル名は Blogger に付いている名前と 1 文字でも違うと、そのブロックは空になる**（空のブロックは表示されない）。

## キャッチコピーを変える

`CONFIG.tagline`。

## 色を変える

`src/site.css` の冒頭、`:root` の中。

| 名前 | 使っている場所 |
|---|---|
| `--teal` | ボタン・ラベル・下線（主役の色） |
| `--teal2` | リンクの文字・英字の小見出し |
| `--ink` / `--ink2` | 本文の文字 / 日付などの薄い文字 |
| `--paper` | 背景画像の下の色 |

文字の色を変えたら、背景との差（コントラスト）を確かめる。目安は 4.5:1 以上。

## ロゴ・背景を変える

`src/assets/` の同じ名前のファイルを差し替える（`logo.png` `logo-white.png` `bg.jpg`）。
背景は 2000px 前後の幅、200KB 以下に縮めてから入れる。

## 見本（preview）で確かめる

`preview/index.html` をブラウザで開く。`preview/` は `src/site.css` を直接読むので、色や配置の変更はすぐ見える。
見本のトップ（`preview/index.html`）は本番と同じ `src/app.js` で動くので、`CONFIG` の変更（トップの並び・開幕演出）も見える。
ほかの見本ページ（記事・一覧など）は `preview/preview.js` が組んでいるので、`CONFIG` は反映されない。
本番と同じ動きは試験用ブログで確かめる。

## トップの開幕演出を変える・やめる

`src/app.js` の `CONFIG.intro`。

```js
intro: { enabled: true, minMs: 2700, maxMs: 4200 },
```

- やめる：`enabled: false`
- `minMs`：演出を最低限見せる長さ（ミリ秒）。記事が早くそろっても、この長さまでは幕を上げない
- `maxMs`：記事が遅くても、この長さで幕を上げる
- 出るのはトップだけ、1 回の訪問で 1 度だけ（同じタブで開き直しても出ない）。幕を押すか、キーを押すと飛ばせる
- 「動きを減らす」設定にしている人には出ない
- 見た目（色・動き）は `src/site.css` の「開幕演出」の節
