# 試験用ブログの作り方

本番とは別の、**部員だけが見られる Blogger のブログ**。新しい版はまずここで確かめる。
壊しても読者には影響しない。

## 作る（最初の 1 回だけ）

報道部の Google アカウントで行う。

1. https://www.blogger.com/ → 左上のブログ名の ▼ → **新しいブログ**
   - 名前：`東北大学新聞（試験用）` など
   - URL：`ton-press-staging.blogspot.com` など（空いていれば）
2. **公開にして、検索エンジンには出さない**
   - 設定 → 権限 → ブログの閲覧者 → **公開**
   - 設定 → クローラとインデックス登録 → 「検索エンジンへの表示を許可」を**オフ**
   - **限定公開にしてはいけない**：限定公開のブログは Blogger がフィードを出さないので、トップの記事が出なくなる（2026-10-07 に実際に起きた）。
     入れるのは本番で公開済みの記事の写しだけなので、公開にしても新しく漏れる情報は無い
3. **本番の記事を写す**
   - Blogger の「コンテンツをバックアップ」は Google Takeout に飛び、写真込みで十数GBになるので使わない
   - 代わりに、本番の公開フィードから記事を取った**軽い取り込みファイル**を作る（最新100件＋トップの各ラベル6件＋固定ページ数枚で1MB弱）。
     作り方：`python scripts/make-staging-import.py`（`staging-import.xml` ができる）
   - 試験用ブログ：設定 → ブログを管理 → **コンテンツをインポート** で読み込む
   - 取り込んだ固定ページは本番と住所が変わる（`/p/blog-page_41.html` → `/p/_2.html` など）。
     メニューのリンクは `app.js` が試験用ブログでだけ題名から引き直すので、そのままでよい
4. （省略可）ブログ一覧に出さない：設定 → 基本 →「ブログをBloggerのリストに表示」をオフ
5. テーマ → ▼ → HTML を編集 → `theme/theme.xml` の全文を貼り付けて保存

## 限界

- コメント・人気記事の数字は本番と同じにならない（試験用ブログのデータなので）
- 本番で記事が増えても、試験用ブログには自動で入らない。必要なら 3. をやり直す
- 試験用ブログで Google アナリティクスなどを有効にしない
- 進路データなど、取り込んでいない記事へのリンクは試験用ブログでは開けない（本番では開ける）

## 確かめること（毎回）

- [ ] トップ：特集が切り替わる／新着記事／ラベル別ブロック
- [ ] 記事ページ：本文・画像・表・共有ボタン・コメント欄
- [ ] スクロールすると、ヘッダーが細くなって上に残る
- [ ] ラベル一覧・検索結果・ページ送り
- [ ] 固定ページ（報道部について・PDF版）
- [ ] スマホ実機（iPhone・Android のどちらか）
