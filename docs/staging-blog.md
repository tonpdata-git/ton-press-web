# 試験用ブログの作り方

本番とは別の、**部員だけが見られる Blogger のブログ**。新しい版はまずここで確かめる。
壊しても読者には影響しない。

## 作る（最初の 1 回だけ）

報道部の Google アカウントで行う。

1. https://www.blogger.com/ → 左上のブログ名の ▼ → **新しいブログ**
   - 名前：`東北大学新聞（試験用）` など
   - URL：`ton-press-staging.blogspot.com` など（空いていれば）
2. **閲覧者を限定する**：設定 → 権限 → ブログの閲覧者 → **限定公開**
   → 「閲覧者を追加」で、確認してほしい部員の Google アカウントを登録（最大 100 人）
   - 登録外の人は、URL を知っていても見られない
3. **本番の記事を写す**
   - 本番ブログ：設定 → ブログを管理 → **コンテンツをバックアップ**（XML が保存される）
   - 試験用ブログ：設定 → ブログを管理 → **コンテンツをインポート** で、その XML を読み込む
   - 「インポートした記事を自動で公開」は **オフ** にしてから公開状態を確かめる
4. **検索エンジンに出さない**：設定 → クローラとインデックス登録 → 「検索エンジンに表示」をオフ
   （限定公開なら出ないが、念のため）
5. テーマ → ▼ → HTML を編集 → `theme/theme.xml` の全文を貼り付けて保存

## 限界

- コメント・人気記事の数字は本番と同じにならない（試験用ブログのデータなので）
- 本番で記事が増えても、試験用ブログには自動で入らない。必要なら 3. をやり直す
- 試験用ブログで Google アナリティクスなどを有効にしない

## 確かめること（毎回）

- [ ] トップ：特集が切り替わる／新着記事／ラベル別ブロック
- [ ] 記事ページ：本文・画像・表・共有ボタン・コメント欄
- [ ] スクロールすると、ヘッダーが細くなって上に残る
- [ ] ラベル一覧・検索結果・ページ送り
- [ ] 固定ページ（報道部について・PDF版）
- [ ] スマホ実機（iPhone・Android のどちらか）
